# My単語

分からなかった単語を自分用に登録し、検索しながら単語帳のようにめくって復習できる静的Webアプリです。

## 使い方

1. `index.html` をブラウザで開きます。
2. 左側のフォームから単語、意味、品詞、同義語、対義語、タグなどを登録します。
3. 右側の単語帳カードをクリック、または `めくる` ボタンで表と裏を切り替えます。
4. 検索、タグ、見る範囲、品詞で絞り込むと、その結果を単語帳としてめくれます。

## 登録できる項目

- 単語
- 意味
- 品詞
- 見つけた場面
- 出典
- 例文
- 同義語
- 対義語
- タグ
- 理解度

## データ保存

登録した単語と背景カラーは、ブラウザのローカルストレージに保存されます。

サーバーや外部サービスには送信されません。別のブラウザや端末へ移したい場合は、画面左側の `CSV出力` と `CSV読込` を使ってください。

## GitHub Pagesで公開する

1. このフォルダの中身をGitHubリポジトリにアップロードします。
2. GitHubのリポジトリ画面で `Settings` を開きます。
3. `Pages` を開きます。
4. `Deploy from a branch` を選びます。
5. `main` ブランチの `/root` を選んで保存します。

数分後にGitHub PagesのURLから開けます。
